# boards/mindmaps/

GENERATED output of `/mindmap` — one Mermaid file per subject per run, named
`<subject>-<YYYY-MM-DD>.md`. Never hand-edit a file here: the next run overwrites it,
and a hand-edit makes the diagram disagree with ClickUp / the org file it was built
from. Fix the SOURCE, then re-run `/mindmap`.

These files are a rendered VIEW, never a registry of live state (CLAUDE.md — right in
one place beats present in two).
